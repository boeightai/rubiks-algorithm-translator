# Bo's Method (Way of the Cube) — Working Spec

Status: Draft for discussion. Not for site implementation. Bo is not ready to change the site yet.

## Bo's Augmentations vs WIRED

1. Daisy edge flipper added to Step 1 (yellow daisy). Bo's personal addition; algorithm TBD.
2. Possible swap of the final edge-cycle PLL in Step 8.

Everything else tracks the WIRED magazine method.

## Steps

### 1. Yellow Daisy
No algorithm in WIRED. Bo's augmentation: add the daisy edge flipper. Algorithm: TBD — Bo to supply.

### 2. White Cross
No algorithm. Same as WIRED.

### 3. First Layer (Bottom Layer Corners)
- Right Trigger: R U R'
- Left Trigger: L' U' L
Same as WIRED.

### 4. Second Layer
- Insert edge to the right: U R U R', then fix displaced corner with a trigger.
- Insert edge to the left: U' L' U' L, then fix the corner the same way.
Same as WIRED.

### 5. Yellow Cross
Algorithm "fururf": F U R U' R' F'
Same as WIRED.

### 6. Solve the Yellow Face
Sune: R U R' U R U2 R'
Same as WIRED. Bo confirmed Sune is included.

### 7. Position the Corners
Corner positioning: L' U R U' L U R' R U R' U R U2 R'
Note: the R' and R cancel, and the back half is Sune. Same as WIRED. Bo confirmed this is included.

### 8. Position the Edges
- Cycle edges clockwise: F2 U R' L F2 L' R U F2
- Cycle edges counterclockwise: F2 U' R' L F2 L' R U' F2
Same as WIRED. This is the PLL pair Bo mentioned he might swap at the very end — mark as the possible swap point.
